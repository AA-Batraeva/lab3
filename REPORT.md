# Отчёт по лабораторной работе №3: Линейные модели

## 1. Данные и подготовка
- **Линейная регрессия (`Student_Performance.csv`)**: Целевая переменная — `Performance Index`. Категориальный признак `Extracurricular Activities` переведен в числа. Данные масштабированы.
- **Классификация (`german.csv`)**: Целевая переменная `Creditability` находится в первом столбце. Выборка разбита на обучающую и тестовую части.

## 2. Гипотезы и эксперименты
- Использован пакетный градиентный спуск с фиксированным числом итераций (1000) для собственной линейной регрессии и логистического классификатора.

## 3. Метрики
- **MSE линейной регрессии**: 4.12
- **Собственная логистическая регрессия**: ROC-AUC = 0.785, Accuracy = 0.750, F1 = 0.828
- **Готовая LogisticRegression**: ROC-AUC = 0.792, Accuracy = 0.756, F1 = 0.834
- **Decision Tree**: ROC-AUC = 0.670, Accuracy = 0.690, F1 = 0.769
- **KNN**: ROC-AUC = 0.730, Accuracy = 0.720, F1 = 0.804
